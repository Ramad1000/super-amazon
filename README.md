# Super Amazon V1.0
حزمة تطوير أولية مبنية على وثيقة المتطلبات V1.0.

## التشغيل
1. أنشئ PostgreSQL database باسم `super_amazon_data`.
2. نفّذ `database/schema.sql`.
3. داخل backend: `npm install` ثم انسخ `.env.example` إلى `.env` وعدّل القيم ثم `npm run dev`.
4. داخل frontend: `npm install` ثم `npm run dev`.

## ملاحظة
هذه حزمة V1.0 تطويرية: الهيكل وقاعدة البيانات والأساسيات موجودة، لكن بعض الوظائف المتقدمة في الوثيقة (مثل التنفيذ الكامل للنسخ الاحتياطي اليومي إلى Telegram وكل صفحات الشكاوى والمالية) تحتاج استكمال مراحل التطوير قبل اعتبارها إنتاجية.
