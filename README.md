# Super Amazon V1.0
حزمة تطوير أولية مبنية على وثيقة المتطلبات V1.0.

## التشغيل
1. أنشئ PostgreSQL database باسم `super_amazon_data`.
2. نفّذ `database/schema.sql`.
3. داخل backend: `npm install` ثم انسخ `.env.example` إلى `.env` وعدّل القيم ثم `npm run dev`.
4. داخل frontend: `npm install` ثم `npm run dev`.

## النسخ الاحتياطي

- تحدد قناة النسخ من لوحة Owner؛ يجب أن يكون البوت مشرفًا فيها.
- تُنشأ نسخة تلقائية يومية بعد الساعة `03:00` بتوقيت بغداد، مع محاولة تعويضية عند عودة الخادم للعمل.
- اضبط `BACKUP_ENCRYPTION_KEY` في Render قبل إنشاء أي نسخة. لا تغيّره لاحقًا، لأن تغيير المفتاح يمنع استعادة النسخ السابقة.
- النسخ الجديدة مشفّرة بـ AES-256-GCM، وتدعم الاستعادة من لوحة Owner بعد كتابة `RESTORE` للتأكيد.
- خطة Render المجانية قد توقف الخدمة عند الخمول؛ للحصول على توقيت مضمون بدقة استخدم خطة غير خاملة أو خدمة جدولة خارجية.
